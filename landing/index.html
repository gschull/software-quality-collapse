Three Gates, One Workflow

🧬 Mutation Testing

Inject fake bugs into your code. If tests don't catch them, your tests are weak. Supports Node (Stryker), Python (mutmut), Java (PIT). Catches 2x more defects than coverage metrics alone.

⚡ Performance Budgets

Block PRs that regress performance. Lighthouse CI for web apps, k6 thresholds for APIs. Define budgets like "first contentful paint < 2s" and enforce them automatically.

🔒 Dependency Health

CVSS scoring, vulnerability counts, and age checks. Supports npm audit, pip-audit, OWASP Dependency-Check. Fail PRs on critical CVEs or warn on old packages.

📊 Hosted Dashboard

Track quality trends over time. No Docker setup—just point your workflow at our ingest endpoint. See mutation scores, CVSS trends, and perf budgets in one place.

🚀 GitHub Actions Native

Reusable workflow with configurable thresholds. Add one YAML block to your repo. Works with Node, Python, Java—more languages coming. PR comments show results instantly.

🎯 ELI5 Documentation

Every concept explained like you're five. No PhD required. "Mutation testing = pretend bugs to test your tests." Clear setup guides, real examples, friendly errors.
